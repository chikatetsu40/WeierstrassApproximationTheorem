    Group presentations as data #

    Group.Presentation extends Group.Generators with a set of relators to form a group presentation as data.

    Main definitions #

    • Group.Presentation G ι: a presentation ⟨ι | rel⟩ of G, extending Group.Generators G ι.

    Main results #

    • Group.Presentation.lift_rel_eq_one: a relator maps to the identity under the canonical surjection.
    • Group.isFinitelyPresented_iff_exists_finite_presentation: A group is finitely presented if and only if it admits a presentation with finitely many generators and finitely many relators.

    Implementation notes #

    • Relators are a Set because (Subgroup.normalClosure, PresentedGroup) take a set as input.
    • The kernel condition lift_ker_eq_normalClosure uses toGenerators.lift as in with Algebra.Presentation.

    References #

    • [D. F. Holt, S. Rees, C. E. Röver, Groups, Languages and Automata][HoltReesRover2017], §1

    structure Group.Presentation (G : Type u_3) (ι : Type u_4) [Group G] extends Group.Generators G ι :
    Type (max u_3 u_4)

    A group presentation is given by a generating family (val : ι → G) and a set of relators (rel : Set (FreeGroup ι)) such that the normal subgroup generated by the relators is exactly the kernel of the canonical lift from the free group on the generators to G.

    • val : ι → G
    • closure_eq_top : Subgroup.closure (Set.range self.val) = ⊤
    • rel : Set (FreeGroup ι)

      The set of relators, as words in the free group; each r ∈ rel is read as r = 1 in G.

    • lift_ker_eq_normalClosure : self.lift.ker = Subgroup.normalClosure self.rel

      The kernel of the canonical surjection is equal to the normal closure of the relators.
