    Convolution product on Hopf algebra maps #

    This file constructs the ring structure on bialgebra homs C → A where C and A are Hopf algebras and multiplication is given by

             |
         μ
|   |   / \
f * g = f g
|   |   \ /
         δ
         |

    diagrammatically, where μ stands for multiplication and δ for comultiplication.

    It also provides:

    • HopfAlgebra.ofAntipodeOfAdjoin, which upgrades a bialgebra A to a Hopf algebra given an algebra hom S : A →ₐ[R] Aᵐᵒᵖ satisfying the antipode identities on a generating set. HopfAlgebra.ofSurjective, which transfers the Hopf algebra axioms along a surjective bialgebra homomorphism intertwining the antipodes.
