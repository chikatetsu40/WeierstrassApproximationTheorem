    Hamiltonian graphs from cyclic permutations #

    If σ is a cycle on a finset s and G.Adj x (σ x) for every x, then the cycle graph on #s vertices embeds in G. In particular, if σ : Perm α is a cycle, 3 ≤ #α, and G.Adj x (σ x) for every x, then G is Hamiltonian.
