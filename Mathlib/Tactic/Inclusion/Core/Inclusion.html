    Constructing inclusions #

    This file defines the main drivers of the inclusion tactic.

    Given an expression e, mkExprInclusionBody recursively applies InclusionExts to construct an ExprInclusionBody for e. Then toExprInclusion applies HypothesisExts to the local context to construct inclusion hypotheses for the body's inclusion variables and closes the body into an ExprInclusion.
