    Datatypes for the inclusion tactic #

    This file defines several datatypes and monads (and some basic API for them) that are used throughout the core of the inclusion tactic.

    source
    structure Inclusion.IType :
    Type

    An IType is a structure that holds the types of an inclusion expression x ∈ s, where the type of x is elemType, the type of s is setType and the ToSet setType elemType instance used is toSetInst.

    • elemType : Lean.Expr

      The element type of an inclusion expression.

    • setType : Lean.Expr

      The set type of an inclusion expression.

    • toSetInst : Lean.Expr

      The ToSet setType elemType instance of an inclusion expression.

        structure Inclusion.IVar :
        Type

        An IVar is a structure that holds the data of a "free inclusion variable" associated to an inclusion expression iExpr. This includes a pair of variables setVar, hypVar (which are sometimes free variables but often synthetic opaque metavariables), where setVar is a variable for an inclusion set and hypVar is a (variable) proof of iExpr.expr ∈ setVar.

        • iExpr : IExpr

          The inclusion expression represented by the inclusion variable.

        • setVar : Lean.Expr

          The inclusion set variable.

        • hypVar : Lean.Expr

          The variable hypVar : iExpr.expr ∈ setVar.

        • cover? : Option Lean.Expr

          An optional expression of type Cover iVar.type.setType iVar.type.elemType. When present, the inclusion computation is mapped over this cover to reduce the "dependency effect".

              structure Inclusion.ExprInclusion :
              Type

              An ExprInclusion is a structure associated with an expression e, containing a computed inclusion set for e and a proof that this inclusion is correct.

              • inclusion : Lean.Expr

                The expression computing an inclusion set for e.

              • proof : Lean.Expr

                A proof of e ∈ inclusion, where e is the represented expression.

                structure Inclusion.ExprInclusionBody :
                Type

                An ExprInclusionBody is an intermediate structure used in the process of building the ExprInclusion associated to an expression e. It contains an inclusionBody and proofBody which contain the (possibly partially completed) body of the inclusion and proof expressions of the ExprInclusion respectively.

                • inclusionBody : Lean.Expr

                  The (possibly partially completed) body of the inclusion expression.

                • proofBody : Lean.Expr

                  The (possibly partially completed) proof of e ∈ inclusionBody.
