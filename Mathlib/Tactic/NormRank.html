    eval_rank: rank of matrix literals by Bareiss elimination #

    This module defines the eval_rank tactic and the norm_rank simproc, which compute the rank of a matrix literal with non-symbolic entries through an Echelon.Decomposition certificate.

        def norm_rank :
        Lean.Meta.Simp.Simproc

        The norm_rank simproc evaluates the rank of matrices with non-symbolic entries. Terms that it cannot evaluate are skipped, since the fallback model accepts every ring and only the evaluation can tell whether an entry is in its scope.
