        Check whether the kernel can reduce decide ((2 : α) ≠ 0) to a boolean result (would be false in characteristic 2). Synthesizing the Decidable instance alone does not settle this, since types such as ℝ have classical instances defined for them. This check tests 2 against 0 (instead of 1), because some rings might have decidable equality facts between 0 and 1, but not for general entries against 0.
