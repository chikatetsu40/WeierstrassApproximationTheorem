    Derivative of the inversion #

    In this file we prove a formula for the derivative of EuclideanGeometry.inversion c R.

    Implementation notes #

    Since fderiv and related definitions do not work for affine spaces, we deal with an inner product space in this file.

    Keywords #

    inversion, derivative

    @[simp]
    theorem EuclideanGeometry.fderiv_inversion_center {F : Type u_2} [NormedAddCommGroup F] [InnerProductSpace ℝ F] {c : F} {R : ℝ} :
    fderiv ℝ (inversion c R) c = 0

    The value of fderiv for inversion at its center is zero. For nonzero radius in a nontrivial space, this is the value assigned by fderiv at a point where the map is not differentiable.
