    Uniquely Decodable Codes #

    This file defines uniquely decodable codes and proves basic properties.

    Main definitions #

    • IsUniquelyDecodable: A set of codewords is uniquely decodable if distinct concatenations of codewords yield distinct strings.

    Main results #

    • IsUniquelyDecodable.epsilon_notMem: Uniquely decodable codes cannot contain the empty string.
    • IsUniquelyDecodable.flatten_injective: The flatten function is injective on lists of codewords from a uniquely decodable code.
