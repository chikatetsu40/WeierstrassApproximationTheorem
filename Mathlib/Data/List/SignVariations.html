    Sign variations of a list #

    This file defines List.signVariations, for counting the number of changes of sign in a list after all zeroes were removed. For example, [1, 0, -2, 3, 3] has two sign variations, and so does [1, -2, 3].

    This is the counting device behind Descartes' rule of signs (applied to the list of coefficients of the polynomial) and Sturm's theorem (applied to the values of a Sturm sequence at a point, or to the signs of its leading coefficients, adjusted by degree parity at -∞, for the count at infinity).

    Main definitions #

    • List.signVariations l: the number of sign variations of l.

    Main results #

    • List.signVariations_cons_cons_of_ne_zero: the recursion for a list starting with two nonzero entries: prepending a to b :: l adds one variation exactly when sign a ≠ sign b.
    • List.signVariations_zero_cons, List.signVariations_cons_zero_cons: zero entries are ignored.
    • List.signVariations_map: signVariations only depends on the signs of the entries, so it is invariant under any map preserving signs (for instance the cast ℚ → ℝ, or SignType.sign itself).
