    Cardinal arithmetic #

    Arithmetic operations on cardinals are defined in Mathlib/SetTheory/Cardinal/Order.lean. However, proving the important theorem c * c = c for infinite cardinals and its corollaries requires the use of ordinal numbers. This is done within this file.

    Main statements #

    • Cardinal.mul_eq_max and Cardinal.add_eq_max state that the product (resp. sum) of two infinite cardinals is just their maximum. Several variations around this fact are also given.
    • Cardinal.mk_list_eq_mk: when α is infinite, α and List α have the same cardinality.
