    Block matrices and their determinant #

    This file defines a predicate Matrix.BlockTriangular saying a matrix is block triangular, and proves the value of the determinant for various matrices built out of blocks.

    Main definitions #

    • Matrix.BlockTriangular expresses that an o by o matrix is block triangular, if the rows and columns are ordered according to some order b : o → α
    • Matrix.IsUpperTriangular and Matrix.IsLowerTriangular, as abbreviations for Matrix.BlockTriangular with the identity and the dual order, respectively.

    Main results #

    • Matrix.BlockTriangular.det: the determinant of a block triangular matrix is equal to the product of the determinants of all the blocks
    • Matrix.det_of_isUpperTriangular and Matrix.det_of_isLowerTriangular: the determinant of a triangular matrix is the product of the entries along the diagonal
