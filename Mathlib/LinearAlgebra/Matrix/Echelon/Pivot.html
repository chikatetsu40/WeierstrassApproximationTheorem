    Pivots of a matrix #

    Matrix.IsPivotedBy A l defines a map-based representation l for the pivot, stating that l i is the pivot column of each row i of A, with ⊤ for a zero row.

    Main definitions #

    • Matrix.IsPivotedBy: l i : WithTop n is the pivot column of each row i of A.

    Main results #

    • Matrix.IsPivotedBy.rank_eq: the rank of a matrix is its number of pivots.
    • Matrix.IsPivotedBy.unique: the pivot of a matrix is unique if the column indices have a linear order.
    • Matrix.isPivotedBy_iff: the map-structural characterisation of pivots.
