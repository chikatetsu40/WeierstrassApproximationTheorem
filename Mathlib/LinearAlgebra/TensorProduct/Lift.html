    Lifting linear maps from base-changed modules #

    This file defines the lift of an R-linear map from M to an A-module N to an A-linear map from A ⊗[R] M to N.

    source
    def LinearMap.liftBaseChangeEquiv {R : Type u_1} {M : Type u_2} {N : Type u_3} (A : Type u_4) [CommSemiring R] [CommSemiring A] [Algebra R A] [AddCommMonoid M] [AddCommMonoid N] [Module R M] [Module R N] [Module A N] [IsScalarTower R A N] :
    (M →ₗ[R] N) ≃ₗ[A] TensorProduct R A M →ₗ[A] N

    If M is an R-module and N is an A-module, then A-linear maps A ⊗[R] M →ₗ[A] N correspond to R-linear maps M →ₗ[R] N by composing with M → A ⊗[R] M, x ↦ 1 ⊗ₜ x.
