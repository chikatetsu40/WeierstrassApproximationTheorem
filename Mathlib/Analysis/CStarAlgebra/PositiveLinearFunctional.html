    Characterization of positive continuous linear functionals on C⋆-algebras #

    In this file we show that a continuous linear functional f on a non-unital C⋆-algebra is monotone if f tendsto ‖f‖ along any/some approximate unit. Therefore, when the algebra is unital, f is monotone if and only if ‖f‖ = f 1.
