    Radial functions #

    A function on a space equipped with a norm is radial if its value at a point depends only on the norm of that point, that is, if it factors through the norm. This file introduces the predicate Function.IsRadial and develops basic API.

    Main definitions #

    • Function.IsRadial: the predicate stating that f : E → F factors through ‖·‖ : E → ℝ.
    • Function.radialPart: a choice of function ℝ → F through which f : E → F factors; it satisfies f = f.radialPart ∘ (‖·‖) precisely when f is radial.
