    Operations on RKHS #

    This file implements the maps that show how RKHSs created from kernels formed by applying operations to a set of kernels relate to the RKHSs of the constituant kernels.

    main definitions #

    • generator: the operator (f, g) ↦ ⇑f + ⇑g inducing the RKHS H + H'.
    • OfKernelAddEquiv: isometric equivalence between the RKHS OfKernel (K + K') and the quotient space over OfKernel K × OfKernel K'.
    • projection: isometry yielding the elements of H × H' achieving the norm of H + H'.
