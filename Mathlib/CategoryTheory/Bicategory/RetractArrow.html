    Retracts of 1-morphisms in bicategories #

    If f : X ⟶ Y and f' : X' ⟶ Y' are 1-morphisms in a bicategory, we introduce a structure RetractArrow₁ f' f expressing that f' is a retract of f, and we show that if f is an equivalence, then f' is also an equivalence.

    Type (max v w)

    A structure expressing that a 1-morphism f' : X' ⟶ Y' in a bicategory is a retract of f : X ⟶ Y.

    • i₁ : X' ⟶ X

      the inclusion of the source object

    • r₁ : X ⟶ X'

      the retraction to the source object

    • i₂ : Y' ⟶ Y

      the inclusion of the target object

    • r₂ : Y ⟶ Y'

      the retraction to the target object

    • id₁ : CategoryStruct.comp self.i₁ self.r₁ ≅ CategoryStruct.id X'

      the source of f' is a retract of the source of f

    • id₂ : CategoryStruct.comp self.i₂ self.r₂ ≅ CategoryStruct.id Y'

      the target of f' is a retract of the target of f

    • commi : CategoryStruct.comp f' self.i₂ ≅ CategoryStruct.comp self.i₁ f

      compatibility of the inclusions

    • commr : CategoryStruct.comp f self.r₂ ≅ CategoryStruct.comp self.r₁ f'

      compatibility of the retractions

    • comm : CategoryStruct.comp (whiskerRight self.commi.hom self.r₂) (CategoryStruct.comp (associator self.i₁ f self.r₂).hom (whiskerLeft self.i₁ self.commr.hom)) = CategoryStruct.comp (associator f' self.i₂ self.r₂).hom (CategoryStruct.comp (whiskerLeft f' self.id₂.hom) (CategoryStruct.comp (rightUnitor f').hom (CategoryStruct.comp (leftUnitor f').inv (CategoryStruct.comp (whiskerRight self.id₁.inv f') (associator self.i₁ self.r₁ f').hom))))
