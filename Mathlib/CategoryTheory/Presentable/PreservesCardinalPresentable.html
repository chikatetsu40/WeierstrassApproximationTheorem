    class CategoryTheory.Functor.PreservesCardinalPresentable {C : Type u_1} {D : Type u_2} [Category.{v_1, u_1} C] [Category.{v_2, u_2} D] (F : Functor C D) (κ : Cardinal.{w}) [Fact κ.IsRegular] :
    Prop

    Let F : C ⥤ D be a functor and κ be a regular cardinal, we say that F.PreservesCardinalPresentable κ holds if for any X : C that is κ-presentable in C, the object F.obj X is κ-presentable in D.
