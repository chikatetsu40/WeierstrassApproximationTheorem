    Accessible functors satisfy the solution set condition #

    If F : C ⥤ D is an accessible functor between accessible categories, then F satisfies the solution set condition (this is corollary 2.45 in the book by Adámek and Rosický).

    References #

    • [Adámek, J. and Rosický, J., Locally presentable and accessible categories][Adamek_Rosicky_1994]
