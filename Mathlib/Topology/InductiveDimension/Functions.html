    Small inductive dimension #

    This file defines a WithBot ℕ∞-valued function which measures the small inductive dimension of a topological space, and connects it to the HasSmallInductiveDimensionLT and HasSmallInductiveDimensionLE typeclasses defined in Topology.InductiveDimension.Classes.

    source

    WithBot ℕ∞
