    The fundamental group of the circle #

    For 0 < p, the fundamental group of AddCircle p at any basepoint is isomorphic to ℤ (AddCircle.windingNumberIso). The winding number AddCircle.windingNumber of a loop is (f 1 - f 0) / p for any continuous lift f : I → ℝ of the loop (AddCircle.windingNumber_eq_div); in particular the loop t ↦ n • (t * p) + x has winding number n (AddCircle.windingNumber_zsmulLoop).
