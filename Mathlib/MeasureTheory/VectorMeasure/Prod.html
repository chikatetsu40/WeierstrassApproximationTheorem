    Product of vector measures #

    Given two vector measures, we define their product μ.prod ν B as the vector measure assigning to a measurable product s × t the mass B (μ s) (ν t), if such a vector measure exists. We show that it exists when either μ or ν has finite variation.

    When both measures have finite variation, we prove stronger results, notably versions of the Fubini theorem. We give general versions for arbitrary pairing functions, and specialized versions for scalar multiplication.

    The API is modelled on the one for the product of positive measures.

    Two vector measures μ and ν have a product with respect to B if there exists a measure giving mass B (μ s) (ν t) to any measurable product set s × t. This is satisfied whenever μ or ν has finite variation.
