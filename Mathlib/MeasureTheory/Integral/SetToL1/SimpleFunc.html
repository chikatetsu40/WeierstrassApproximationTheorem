    Extension from set functions to integrable simple functions #

    This file is the first stage in extending a dominated finitely-measure-additive set function T : Set α → E →L[ℝ] F to integrable functions. It defines L1.SimpleFunc.setToL1S on integrable simple functions, proves its algebraic, norm, and order properties, and packages it as the continuous linear map L1.SimpleFunc.setToL1SCLM.
