    Extension of set functions to integrable functions #

    This file defines MeasureTheory.setToFun, the function-level version of MeasureTheory.L1.setToL1. It applies the L¹ extension to an integrable function and is defined to be zero when the function is not integrable or the target is not complete.

    The file proves the core algebraic, congruence, order, indicator, simple-function, and continuity properties of setToFun, including continuity under convergence in L¹.

    Extend T : Set α → E →L[ℝ] F to (α → E) → F (for integrable functions α → E). We set it to 0 if the function is not integrable or if the target space is not complete.
